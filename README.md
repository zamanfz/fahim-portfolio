# Fahim Zaman — Portfolio

A responsive, animated developer portfolio with a dark editorial design, lime accents, project galleries, interactive mission tabs, and image lightboxes.

## Requirements
- Node.js (LTS recommended)
- npm

## Run locally (Windows PowerShell)
Open this folder in PowerShell and run:

```powershell
npm.cmd install
npm.cmd run dev
```

Open the local URL printed by Vite, usually http://localhost:5173/.

## Production build
```powershell
npm.cmd run build
npm.cmd run preview
```

## Included images
Project screenshots and profile photos are in `public/images/`. Keep the folder structure intact.

## Before publishing
- Review each project description and repository link to ensure it matches what you can demonstrate.
- The CloudSentinel, HPCC AI Monitor, and TeaTrace cards currently link to your GitHub profile where a dedicated repository URL wasn't provided.
- Your Computer Vision card links to `https://github.com/zamanfz/Underwater-trash-detection`.
- Your contact email and LinkedIn profile are configured in the page.

## Deploy
Build command: `npm run build`; output directory: `dist`. You can deploy on Vercel or Netlify.
